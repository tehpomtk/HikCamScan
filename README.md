# HikCamScan

Нативное Android-приложение для инвентаризации собственных камер Hikvision и ONVIF. Android 10+. Java 17, без сторонних библиотек в приложении.

## Возможности

- Multicast-обнаружение Hikvision SADP (UDP 37020) и ONVIF WS-Discovery (UDP 3702), объединение по IP.
- Ручное добавление локального IPv4 и HTTP/ONVIF-портов.
- До трёх заданных пользователем пар логин/пароль. Последовательная проверка, остановка после успеха, пауза между учётными записями и 5 минут перед повторной проверкой камеры.
- Модель, IP, MAC, серийный номер и прошивка, когда камера предоставляет эти сведения.
- Hikvision ISAPI: HTTP Basic/Digest MD5/SHA-256; ONVIF: UsernameToken PasswordDigest и HTTP-аутентификация.
- Получение одиночного кадра через ISAPI или ONVIF Media GetSnapshotUri. Сохранение в галерею Pictures/HikCamScan.
- Пароли только в памяти, без логирования; резервное копирование отключено. Снимки сохраняются в закрытой папке приложения; экспорт в галерею по кнопке.

## Использование

1. Подключите телефон к сети камер. Нажмите «Сканировать». Изоляция Wi-Fi клиентов, VLAN и фильтрация multicast могут мешать поиску; в таком случае добавьте IP вручную.
2. В «Учётные записи» укажите 1–3 известных вам пары. Встроенного словаря паролей нет.
3. Нажмите «Получить снимок» на камере или «Снимки всех». Подтвердите право доступа к выбранным устройствам.
4. Сохраните нужный кадр кнопкой «В галерею».

## Ограничения первой версии

- Реальные камеры и Android-устройство ещё требуют полевой проверки. APK — debug-сборка для установки и испытаний.
- Неверные пароли могут вызвать блокировку на камере даже при трёх учётных записях. Кулдаун приложения не отменяет политику блокировки устройства и сбрасывается при перезапуске приложения.
- ONVIF должен быть включён на камере; для него может требоваться отдельный пользователь. PasswordDigest зависит от синхронизации времени телефона и камеры; автоматической коррекции времени пока нет.
- Реализован ONVIF Media v1, без Media2, RTSP-декодирования, SDK/порта 8000 и live-видео. ISAPI используется как HTTP-протокол Hikvision; SADP — только для обнаружения. Сброс паролей и изменение настроек устройств отсутствуют.
- MAC читается из SADP или API камеры; Android не предоставляет универсального доступа к ARP-таблице. Отсутствующие данные показываются явно.
- При отключённом HTTP/ISAPI может понадобиться ONVIF. HTTPS из адресов обнаружения поддерживается со стандартной проверкой сертификатов; самоподписанные сертификаты автоматически не принимаются. Ручной ввод сейчас использует HTTP.
- История устройств и учётные записи не восстанавливаются после перезапуска. Старый снимок остаётся в карточке, если обновление не удалось; статус показывает ошибку последнего запроса.
- Работа в foreground, без фонового сервиса. Только частные и link-local IPv4 адреса. Автоматических TCP-сканов подсетей нет.

## Сборка

JDK 17+, Android SDK platform 36. Gradle 9.3.1, Android Gradle Plugin 9.1.0. Откройте проект в Android Studio или выполните `./gradlew :app:assembleDebug` (Windows: `gradlew.bat`). В `local.properties` укажите `sdk.dir`.

На подготовленном сервере `tools/build-server.sh` собирает APK и запускает интеграционный тест HTTP на локальном эмуляторе камеры, проверки Digest, XML и адресов. APK: `dist/HikCamScan-debug.apk`.
